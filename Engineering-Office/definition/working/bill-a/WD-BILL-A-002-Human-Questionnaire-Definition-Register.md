## 1. Cycle

```text
HUMAN INTENT
→ BOUNDED QUESTION

→ EVIDENCE REQUIREMENT
→ EVIDENCE / UNKNOWN / CONFLICT
→ LOU RECORD
→ HUMAN REVIEW

```

Classification of each Human answer:

| Class | Meaning |
|---|---|
| HUMAN INTENT | What the Human Engineer wants |
| PROPOSED UNDERSTANDING | Candidate agreed-understanding text for later HG-D1 |
| FACTUAL CLAIM REQUIRING EVIDENCE | External fact; not established by intent alone |
| ASSUMPTION | Adopted only if Human so classifies |
| OPEN QUESTION | Remains unresolved |
| REJECTED INTERPRETATION | Expressly not adopted |
| DEFERRED ITEM | Parked with reason |

Human intent is never converted into an asserted Kansas legal or fiscal fact.
