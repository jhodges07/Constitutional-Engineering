## 1. Purpose

Define the production contract that governs how the proven ChatGPT ↔ GitHub ↔ Cursor interchange (**CWC-CE-074 FULL PASS**) may later be used to support the Human command:

```text
Prepare this week's BlueprintLiberty status.
```

That command’s simplicity **SHALL NOT** bypass this control structure.

---

## 2. Human Trigger

1. **Ordinary weekly trigger (target):** Human Engineer issues an authorized work card or explicit command equivalent to “Prepare this week’s BlueprintLiberty status.”  
2. **Silence is not authorization** (POL-001 / WF-001).  
3. ChatGPT or Cursor **SHALL NOT** self-initiate a weekly package.  
4. Phone-initiated work (future) is a **Human trigger channel**, not an AI autonomy grant.

---

## 3. Evidence Cutoff

1. Each weekly package SHALL declare an **Evidence Cutoff** timestamp (timezone America/Chicago unless HE directs otherwise).  
2. Evidence collected after the cutoff is **out of scope** for that week unless HE amends the cutoff.  
3. Prior week’s committed package (when present) is the default comparison baseline for change detection.

---

## 4. Authorized Evidence Sources (Candidate Set)

Until a later CONTROL narrows or expands this list, candidate authorized sources for evidence collection are:

1. `jhodges07/Constitutional-Engineering` (canonical)  
2. Other `X:\GitHub` / GitHub repositories **only when** the authorizing CWC expressly names them  
3. Controlled Engineering Definition artifacts (e.g., accepted LOU-002; LOU-001 as applicable)  
4. Prior Human-approved weekly status packages under `publication/weekly-status/`  

**Not authorized as engineering truth:**

- Facebook / social posts  
- Unverified conversation memory  
- Generative-image “remembered” appearance  
- Informal notes outside repository controls  

Research remains **informative** unless promoted through controlled acceptance (POL-001).

---

## 5. Repository Evidence Collection

Proposed Sunday / on-demand sequence (architecture target; not scheduled automation):

1. Confirm authorizing CWC / HE trigger.  
2. Fetch authorized remotes using repository-safe Git procedures.  
3. Inventory commits, controlled-document changes, and open engineering artifacts since prior Evidence Cutoff.  
4. Record evidence citations (path + commit SHA where applicable).  
5. Produce an **Evidence Digest** (candidate; non-operative) for HE review.

ChatGPT may draft the digest via GitHub interchange where authorized.  
Cursor verifies local/remote consistency where authorized.  
Neither may invent missing evidence.

---

## 6. Weekly Change Detection

1. Compare current Evidence Digest to prior week’s approved package (or HE-declared baseline).  
2. Classify changes as: material / informational / out-of-scope / unknown.  
3. Unknown or conflicting evidence → **STOP for Human decision** (do not guess).

## 14. FIXED vs VARIABLE Image Fields

### FIXED (ordinary weekly cycle — do not change without controlled HE change)

Image dimensions/aspect; layout; title; section positions; typography; colors; icons; Value Stream layout; repository names/descriptions; Bill A/B/C titles; BlueprintLiberty.com spelling/placement; motto; fixed explanatory text; other HE-approved visuals.

## 15. Anti-Drift Validation

Before package acceptance, verify:

1. FIXED elements unchanged vs approved baseline.  
2. Only VARIABLE fields differ for the week.  
3. Challenge/spelling checks for BlueprintLiberty.com.  
4. Markdown ↔ image filename date pairing.  
5. Percentages match Human-approved values exactly.  

Failure → **STOP**; do not publish.
